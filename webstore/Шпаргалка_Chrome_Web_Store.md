# Шпаргалка для публікації TalonTermo у Chrome Web Store

Усі файли для завантаження вже готові в папці `d:\MyProject\TalonAuto\webstore\`.

---

## Крок 0. Кабінет розробника
1. Перейди на **https://chrome.google.com/webstore/devconsole** під своїм Google-акаунтом.
2. Якщо заходиш уперше — оплати одноразовий реєстраційний внесок **\$5** (платиться 1 раз назавжди).
3. Натисни **«+ New item»** (Новий елемент).

---

## Вкладка 1: Package (Пакет)
1. Натисни **Browse files** і завантаж файл:
   `d:\MyProject\TalonAuto\webstore\TalonTermo_ChromeWebStore.zip`

---

## Вкладка 2: Store listing (Сторінка в магазині)
- **Title (Назва):** *(підтягнеться автоматично з `manifest.json`)*
  `TalonTermo — Імпорт талонів з PDF у TermoUnion CRM`
- **Summary (Короткий опис):** *(підтягнеться автоматично)*
  `Автоматична нарізка паливних талонів із PDF, розпізнавання полів, перевірка дублів у базі та завантаження в TermoUnion CRM.`
- **Description (Детальний опис — скопіюй і встав):**
  ```text
  Розширення TalonTermo автоматизує завантаження паливних талонів із PDF-файлів у панель адміністратора TermoUnion CRM (driver.tun.com.ua/admin/tickets).

  Основні можливості:
  • Автоматична нарізка кожного талона з багатосторінкових PDF (сітки 3×3, 1×1 тощо) у якісний PNG-скріншот.
  • Автоматичне розпізнавання полів: АЗС, тип пального (ДП, А-95, А-92, Газ), номінал, термін придатності та серійний номер.
  • Перевірка дублів безпосередньо в базі CRM (вільні, видані/активні, використані) — задубльовані рядки підсвічуються червоним із лічильником та видаляються в 1 клік.
  • Масове редагування полів і пакетне завантаження всіх талонів у CRM.
  • Повна локальна обробка в пам’яті браузера — PDF-файли та номери талонів не передаються на сторонні сервери.
  ```
- **Category (Категорія):** `Workflow & Planning` (або `Productivity`)
- **Language (Мова):** `Ukrainian (Українська)`
- **Store icon (`128×128`):** завантаж `d:\MyProject\TalonAuto\webstore\store_icon_128x128.png`
- **Screenshots (`1280×800`):** завантаж `d:\MyProject\TalonAuto\webstore\screenshot_1280x800.png`
- **Small promo tile (`440×280`):** *(необов’язково, але бажано)* завантаж `d:\MyProject\TalonAuto\webstore\promo_tile_440x280.png`

## Вкладка 3: Privacy practices (Конфіденційність)

### 1. Single purpose description (Єдине призначення):
```text
Автоматична нарізка зображень паливних талонів із завантажених користувачем PDF-файлів, розпізнавання реквізитів та їх пакетна відправка у веб-форму адмін-панелі TermoUnion CRM.
```

### 2. Permission justification — Host permission (`https://driver.tun.com.ua/admin/tickets*`):
```text
Доступ обмежений виключно сторінкою адмін-панелі TermoUnion CRM (https://driver.tun.com.ua/admin/tickets*) для відображення кнопки «Імпорт з PDF», перевірки вже наявних номерів талонів у базі (запобігання дублям) та відправки розпізнаних талонів у межах поточної авторизованої сесії користувача.
```

### 3. Remote code (Використання віддаленого коду):
- Обери: **«No, I am not using remote code»** *(Ні, я не використовую віддалений код)* — уся бібліотека `pdf.js` вшита локально всередину `.zip`.

### 4. Data usage (Використання даних):
- Залиш **усі** галочки збору даних **ВИМКНЕНИМИ** (розширення не збирає і не передає персональні дані, історію чи вміст файлів розробнику або третім сторонам).
- Унизу постав **усі 3 галочки сертифікації** (що дані не продаються, не передаються і використовуються лише для основної функції розширення).

## Вкладка 4: Distribution (Розповсюдження)
- **Pricing (Ціна):** `Free` (Безкоштовно)
- **Visibility (Видимість — обери потрібний варіант):**
  - **Unlisted («Доступ за посиланням»)** — *рекомендовано для компанії:* у пошуку Chrome Web Store ніхто чужий не знайде, але кожен, кому ти даси посилання, встановить у 1 клік.
  - **Public («Публічне»)** — якщо хочеш, щоб знаходилось і через пошук магазину.
- Натисни **Save draft**, а потім **Submit for review**.

*(Перевірка Google зазвичай триває 1–2 дні, оскільки розширення не запитує жодних небезпечних дозволів і працює лише на одному домені).*
