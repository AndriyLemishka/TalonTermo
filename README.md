# TalonTermo (TalonAuto)

Розширення для Google Chrome, яке прямо на сторінці `https://driver.tun.com.ua/admin/tickets` нарізає паливні талони з PDF (3×3, 1×1, багатосторінкові), розпізнає поля (АЗС, тип пального, номінал, термін придатності, номер талона) та автоматично додає їх у TermoUnion CRM.

---

## Встановлення та оновлення однією командою (Windows CMD)

Не потребує встановлення Git або Python. Відкрий **Командний рядок (`cmd`)** (або `Win + R` → `cmd`) і виконай:

```cmd
powershell -NoProfile -ExecutionPolicy Bypass -Command "irm https://raw.githubusercontent.com/AndriyLemishka/TalonTermo/main/install.ps1 | iex"
```

Що зробить команда:
1. Завантажить найсвіжішу версію розширення в `%LOCALAPPDATA%\TalonTermo\extension`.
2. Створить на Робочому столі ярлик `Оновити_TalonTermo.cmd` для оновлення в 1 клік.
3. Скопіює шлях до папки розширення в буфер обміну.

### Перше підключення в Google Chrome (1 раз)
1. Відкрий у Chrome: **`chrome://extensions`**
2. Праворуч угорі увімкни **«Режим розробника»** (*Developer mode*).
3. Натисни **«Завантажити розпаковане»** (*Load unpacked*).
4. Натисни **`Ctrl+V`** (шлях уже в буфері обміну) та **Enter**.
5. Відкрий або онови (`F5`) сторінку **`https://driver.tun.com.ua/admin/tickets`** — з’явиться кнопка **«📄 Імпорт з PDF»**.

### Як оновлювати потім
Коли на GitHub вийде нова версія, у вікні розширення з’явиться жовтий банер **«🔔 Доступна нова версія»**. Запусти ярлик **`Оновити_TalonTermo.cmd`** на Робочому столі (або ту саму команду в `cmd`) і онови сторінку в Chrome (`F5`).

---

## Безпека
- Обробка PDF і нарізка зображень відбувається **локально в пам’яті браузера** за допомогою вбудованої бібліотеки `pdf.js`.
- Жодні файли, талони, номери чи паролі не передаються на сторонні сервери.
- Розширення працює лише на URL `https://driver.tun.com.ua/admin/tickets*` і не має дозволів на доступ до інших вкладок.
